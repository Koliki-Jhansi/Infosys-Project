⚙️ Jira Cloud Configuration

To enable automated and manual Jira issue creation for escalated passenger tickets, configure the following variables in your server's .env file:

# Jira Cloud REST API v3
JIRA_BASE_URL=https://your-domain.atlassian.net
JIRA_EMAIL=your-jira-email@example.com
JIRA_API_TOKEN=your-jira-api-token
JIRA_PROJECT_KEY=SUP
JIRA_ISSUE_TYPE=Task
Note: Generate an API token from your Atlassian Security Settings. After updating your .env file, restart the server or click Retry Jira Sync.
